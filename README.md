I designed a Common Source Amplifier using Cadence Virtuoso 90nm Technology
here common source means the source is grounded which is common both to the input and output

Voltage gain we get in the circuit is Av​=−gm​RD, where gm is the transconductance and RD is the resistance connected at the drain terminal of the mosfet
minus symbol indicates the 180 degree phase shift between the input & output

here, mosfet must operate in the saturation region for amplification that is vds > vgs-vth
